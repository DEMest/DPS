# Задача C1

## Условие

Дан алфавит — список строк из одного символа — и число **N**. Нужно описать функцию,
которая возвращает все строки длины N из символов алфавита, в которых нет двух одинаковых
символов подряд.

Использовать операции **map / reduce / filter / remove** и базовые операции над списками:
**str**, **cons**, **.concat** и т. п. Без рекурсии, генераторов и продвинутых функций
вроде **flatten**.

Пример: для алфавита `("a" "b" "c")` и N = 2 результат — `("ab" "ac" "ba" "bc" "ca" "cb")`
с точностью до перестановки.

## Решение

[src/c1/core.clj](src/c1/core.clj), функция `words`:

```clojure
(words '("a" "b" "c") 2)   ;; => ("ab" "ac" "ba" "bc" "ca" "cb")
```

Слова строятся по одному символу за шаг. Начинаем со списка из одного пустого слова и
N раз заменяем каждое слово на все его продолжения:

* `extend-word` — продолжения одного слова: `remove` убирает из алфавита символ, которым
  слово уже заканчивается, `map` дописывает каждый оставшийся символ к слову через `str`;
* `extend-words` — продолжения всех слов: `map` по словам, а `apply concat` склеивает
  полученные списки в один;
* `words` — `reduce` повторяет шаг N раз: `(range n)` служит только счётчиком шагов.

Для алфавита из k символов получается k·(k−1)^(N−1) слов: первый символ — любой, каждый
следующий — любой, кроме предыдущего.

Списки склеиваются через `apply concat`, а не через `concat` внутри `reduce`. Второй
вариант вкладывает `concat` друг в друга по одному на каждое слово, и уже на 49 152 словах
(алфавит из 3 символов, N = 15) чтение результата падает со `StackOverflowError`.

Тесты — [test/c1/core_test.clj](test/c1/core_test.clj): пример из условия, крайние случаи
(N = 0, алфавит из одного символа, пустой алфавит), сравнение с полным перебором, число
слов по формуле, большие N.

## Что нужно

* **JDK** — подойдёт тот же JDK 21, что и для J1.
* **Leiningen** — сборщик Clojure-проектов, аналог Gradle. Проект описан в `project.clj`
  (аналог `build.gradle`). Сам Clojure отдельно ставить не нужно: это обычная библиотека,
  Leiningen скачает её из Maven Central при первом запуске.

### Установка Leiningen на macOS

Через [Homebrew](https://brew.sh):

```
brew install leiningen
lein version
```

`lein version` должна напечатать версию Leiningen и Java. Если Java нет или она старше 21,
поставьте её тоже: `brew install openjdk@21` (команда в конце установки подскажет, как
сделать её системной).

### Установка Leiningen на Windows

1. Скачать `lein.bat` со страницы [leiningen.org](https://leiningen.org) (раздел Install).
2. Положить его в папку, которая есть в `PATH`, например создать `C:\tools`, положить туда
   `lein.bat` и добавить `C:\tools` в `PATH` (Параметры → «Изменение переменных среды»).
3. В новом окне cmd или PowerShell выполнить `lein self-install` — скачается сам Leiningen.
4. Проверить: `lein version`.

Вместо шагов 1–3 можно поставить через менеджер пакетов: `scoop install leiningen` или
`choco install lein`.

### Установка Leiningen в Linux и WSL

Скрипт `lein` с той же страницы: сделать исполняемым (`chmod +x lein`), положить в `PATH`,
первый запуск сам скачает Leiningen.

### Если путь к домашнему каталогу содержит кириллицу (Windows)

Если путь к домашнему каталогу содержит кириллицу и lein падает с ошибкой про путь или
«Could not find or load main class» (та же причина, что у Gradle в J1), перенесите
служебные папки Leiningen на ASCII-путь: задайте переменную окружения `LEIN_HOME=C:\lein`
и создайте файл `C:\lein\profiles.clj`, чтобы и скачанные библиотеки лежали не в
`%USERPROFILE%\.m2`:

```clojure
{:user {:local-repo "C:/m2"}}
```

## Запуск

Из этой папки (`C1`):

```
lein test                  # тесты
lein run                   # пример из условия: алфавит abc, N = 2
lein run abcd 3            # свой алфавит (строкой, по символу на букву) и N
lein repl                  # интерактивная консоль (REPL)
lein uberjar               # собрать один jar со всеми зависимостями
java -jar target/uberjar/c1-0.1.0-SNAPSHOT-standalone.jar abcd 3
```

В REPL: `(require '[c1.core :as c1])`, затем `(c1/words '("a" "b" "c") 2)`.

Первая команда скачает Clojure и библиотеки для REPL в `~/.m2` (на Windows —
`%USERPROFILE%\.m2`), для этого нужен интернет. Собранное складывается в `target/`,
в репозиторий эта папка не попадает.

Что должно получиться:

```
$ lein run
("ab" "ac" "ba" "bc" "ca" "cb")

$ lein test
...
Ran 13 tests containing 41 assertions.
0 failures, 0 errors.
```

## Редактор

На Лиспе тяжело писать без редактора, который понимает скобки и умеет отправлять код в REPL.
Подойдёт любой из двух:

* **VS Code + расширение Calva.** Открыть папку `C1`, выполнить команду
  «Calva: Start a Project REPL and Connect (aka Jack-In)» (`Ctrl+Alt+C`, затем `Ctrl+Alt+J`)
  и выбрать Leiningen. `Ctrl+Enter` вычисляет выражение под курсором, `Alt+Enter` —
  выражение верхнего уровня (например, всю функцию), результат появляется рядом с кодом.
* **IntelliJ IDEA + плагин Cursive** — подробно ниже.

### IntelliJ IDEA + Cursive

1. **Плагин.** Settings → Plugins → Marketplace → `Cursive` → Install, перезапустить IDE.
   При первом запуске Cursive попросит лицензию — выбрать бесплатную Non-Commercial.
2. **Проект.** Если открыт весь репозиторий `DPS`, Cursive не знает, что `C1` — проект
   Clojure: View → Tool Windows → Leiningen → «+» → выбрать `C1/project.clj`. Другой
   вариант — открыть `C1/project.clj` отдельным проектом (File → Open → Open as Project).
   В Project Structure → Project должен стоять JDK 21.
3. **REPL.** Run → Edit Configurations → «+» → Clojure REPL → Local, оставить nREPL и
   Run with Leiningen, указать модуль `c1` → OK → Run. Внизу откроется окно REPL; пока его
   нет, в строке состояния написано «No REPL».
4. **Код в REPL.** В открытом файле правая кнопка → REPL → Load File in REPL — загрузить
   файл целиком, Send Top Form to REPL — вычислить функцию под курсором. Дальше в окне
   REPL можно вызвать `(c1.core/words '("a" "b" "c") 2)`. Горячие клавиши для этих команд
   назначаются в Settings → Keymap (поиск по названию команды).
5. **Тесты.** В файле `test/c1/core_test.clj`: правая кнопка → REPL → Run Tests in Current
   NS in REPL. Или окно Leiningen → Tasks → `test`.
6. **Запуск `-main`.** Окно Leiningen → Tasks → `run`, или во встроенном терминале
   (`⌥F12` на macOS, `Alt+F12` на Windows) — `lein run abc 3`.

Обычный цикл работы: запустить REPL, написать функцию, вычислить её, попробовать на
данных прямо в редакторе (удобно в блоке `(comment ...)` в конце файла), исправить,
вычислить снова; в конце — закрепить поведение тестами и запустить `lein test`.

соответствует подчёркиванию в имени файла.

# DPS — задачи курса Data Structure and Processing

Каждая задача лежит в своей папке и представляет собой самостоятельный Gradle-проект:
со своей обёрткой `gradlew`, своими зависимостями и своим описанием. Папку можно собрать
и запустить отдельно от остального репозитория.

| Задача | Что это | Описание |
|---|---|---|
| [J1](J1) | Сервер генерации ключей: TCP-микросервис, выдающий пары ключей RSA и сертификаты X509 | [J1/README.md](J1/README.md) |

## Как собрать любую задачу

```
cd J1
gradlew.bat build
```

Подробности запуска — в README внутри папки задачи.

## Общие материалы

Готовые jar-файлы в репозиторий не кладутся (см. `.gitignore`) — ни собранные артефакты,
ни выданные к задачам. Исключение одно: `gradle/wrapper/gradle-wrapper.jar`, без него
проект не собрать после клонирования.

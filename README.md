# DPS — задачи курса Data Structure and Processing

Каждая задача лежит в своей папке и представляет собой самостоятельный проект со своими
зависимостями и своим описанием. Папку можно собрать и запустить отдельно от остального
репозитория. Задачи J — на Java, это Gradle-проекты со своей обёрткой `gradlew`; задачи C —
на Clojure, это проекты Leiningen.

| Задача | Что это | Описание |
|---|---|---|
| [J1](J1) | Сервер генерации ключей: TCP-микросервис, выдающий пары ключей RSA и сертификаты X509 | [J1/README.md](J1/README.md) |
| [J2](J2) | Синхронизированный доступ к списку: связный список с блокировкой отдельных записей, сортируемый пузырьком из нескольких нитей | [J2/README.md](J2/README.md) |
| [J3](J3) | Асинхронный обход ресурсов HTTP-сервера на виртуальных нитях | [J3/README.md](J3/README.md) |
| [C2](C2) | Бесконечная последовательность простых чисел: решето Эратосфена без верхней границы | [C2/README.md](C2/README.md) |

## Как собрать любую задачу

Задача на Java:

```
cd J1
gradlew.bat build
```

Задача на Clojure (нужен установленный [Leiningen](https://leiningen.org)):

```
cd C1
lein test
```

Подробности запуска — в README внутри папки задачи.

## Общие материалы

Готовые jar-файлы в репозиторий не кладутся (см. `.gitignore`) — ни собранные артефакты,
ни выданные к задачам. Исключение одно: `gradle/wrapper/gradle-wrapper.jar`, без него
проект не собрать после клонирования.
